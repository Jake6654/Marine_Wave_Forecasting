### 계획했던 기간과 실제 파일의 차이

비교 기준은 B1에서 계획한 `2025-01-01 00:00`부터 `2025-01-07 23:00`까지다.
실제 다운로드 화면에서 선택한 시작·종료 시간은 이 CSV만으로 복원할 수 없다.

| 비교 항목 | 시각 수 | 파일에 있는 시각 | 파일에 없는 시각 | 포함 비율 |
|---|---:|---:|---:|---:|
| 계획한 7일의 매시간 시각 | 168 | 125 | 43 | 74.40% |
| 실제 최초·최종 기록 사이의 매시간 시각 | 144 | 125 | 19 | 86.81% |

계획 기간에서 파일에 없는 43개 시각은 다음처럼 구분된다.

- 실제 최초·최종 기록 사이: 19개 시각.
- 최초 기록 이전: `2025-01-01 00:00` 1개 시각.
- 최종 기록 이후: `2025-01-07 01:00`부터 `23:00`까지 23개 시각.
- 계획 기간 밖에 있는 레코드: 0개.

이 수치는 현재 파일에 해당 시각의 행이 없다는 뜻이다. 관측장비의 결측률을 의미하지
않는다. 다운로드 범위, 제공 방식, 필터링, 실제 관측 누락 중 무엇이 원인인지는 미확인이다.

| 검사 | 결과 |

| 전체 열의 빈 문자열 또는 공백만 있는 셀 | 0개 |
| 기상 수치 8개 열의 숫자 변환 실패 | 0개 |
| 기상 수치 8개 열의 NaN·무한대 | 0개 |
| 기상 수치 8개 열의 0 값 | 0개 |
| 기상 수치 8개 열의 음수 값 | 0개 |
| 공식 결측 대체값 규칙 | 미확인 |

모든 기상 수치 열에는 각각 125개의 유한한 숫자가 있다. 빈 셀이 없더라도
관측시각의 행 자체가 없는 경우는 존재하므로, 연속적인 시간자료라고 볼 수는 없다.
숫자로 변환된다고 제공기관의 품질 검사를 통과한 정상 관측값임이 증명되는 것은 아니다.

일부 수치는 소수점 앞의 0이 생략되어 있다.

| 원본 문자열 예시 | 수치 해석 | 해당 열에서 소수점으로 시작하는 값 수 |
|---|---:|---:|
| 기온 `.6` | 0.6°C | 14 |
| 유의파고 `.5` | 0.5m | 96 |
| 평균파고 `.3` | 0.3m | 119 |

원본 문자열은 수정하지 않았다.

## 6. 수치 요약

빈 값과 비유한 숫자가 없어 각 수치 열의 125개 값을 모두 사용했다.
평균은 소수 넷째 자리까지 표시했다. 범위와 평균은 이 샘플에만 해당한다.

| 열 | 최솟값 | 최댓값 | 산술평균 | 중앙값 |
|---|---:|---:|---:|---:|
| 풍속(m/s) | 1.1 | 12.7 | 5.8640 | 5.3 |
| 풍향(deg) | 1 | 359 | 계산하지 않음 | 계산하지 않음 |
| 현지기압(hPa) | 1015.2 | 1028.5 | 1023.1088 | 1023.8 |
| 습도(%) | 33 | 85 | 58.7360 | 58 |
| 기온(°C) | 0.1 | 7.8 | 3.7520 | 3.2 |
| 수온(°C) | 8.1 | 9.0 | 8.4296 | 8.4 |
| 유의파고(m) | 0.2 | 2.2 | 0.7328 | 0.6 |
| 평균파고(m) | 0.2 | 1.3 | 0.4424 | 0.4 |

풍향은 0도와 360도가 같은 방향인 원형 자료다. 일반적인 산술평균이나
선형 중앙값으로 대표 방향을 해석하지 않도록 위 표에서 제외했다.

## 7. 분석 방법과 확인 범위

- 원본을 CP949로 엄격 디코딩하고 Python 표준 라이브러리 `csv`로 전체 레코드를 파싱했다.
- 날짜 형식은 `%Y-%m-%d %H:%M`으로 검증했다.
- 수치는 `Decimal`로 읽어 빈 문자열, 숫자 변환 실패, 비유한 값과 기본 통계를 확인했다.
- 시간 비교는 정확한 시각 집합으로 수행했다. 행 번호로 시간을 추정하지 않았다.
- 별도의 pandas 파싱으로 행·열 수, 빈 셀, 중복 키, 계획 기간의 부재 시각 수,
  실제 기록 구간의 시각 수와 부재 시각 수, 유의파고 평균을 교차 확인했다.
- 분석 전후 원본 바이트와 SHA-256이 동일함을 확인했다.

## 8. 추가 확인이 필요한 데이터 사항

1. 원본 시간대의 공식 근거. 현재 CSV에는 시간대가 표시되어 있지 않다.
2. 실제 다운로드 시작·종료 시간. 최종 기록이 1월 7일 00시인 이유는 미확인이다.
3. 중간에 없는 19개 시각의 원인. 원본 제공 화면이나 다른 제공 경로와 대조가 필요하다.
4. 공식 결측 대체값 규칙, 품질 검사 및 필터링 방식.
5. 원래 다운로드 파일명, 정확한 다운로드 시각, 이용 조건의 상세 기록.

현재 샘플은 열 구조와 숫자·시간 파싱을 확인하는 데 사용할 수 있다.
장기간 관측의 가용성, 계절 대표성, 모델 성능은 이 샘플로 검증하지 않았다.
