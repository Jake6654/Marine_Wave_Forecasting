# 첫 배포 모델 선택 및 최종 평가 전 설정 고정

작성일: 2026-10-23  
선택 모델: RandomForestRegressor  
상태: 검증 결과에 따른 선택과 평가 계획을 문서로 고정함. 최종 테스트 성능은 미평가.

## 1. 이 문서의 책임

최종 테스트 결과를 보기 전에 모델 선택 이유, 입력 특성, 학습 설정,
평가 방법을 기록한다. 데이터 시간대 변환은 `kst_reprocessing.md`,
학습 구현은 `src/marine_forecast/training.py`가 담당한다.
이 문서는 그 코드를 복제하지 않고 실험의 의사결정과 고정 조건을 담당한다.

여기서 고정은 실험 절차에 대한 약속이다. 코드를 자동으로 잠그거나,
학습된 모델 파일을 저장하거나, 배포했다는 뜻은 아니다.

## 2. 예측 문제와 데이터 흐름

지점 22101에서 기준시각 t까지의 관측으로 정확히 t+6시간의 유의파고(m)를
예측한다. 향후 6시간 동안의 최대 파고나 사고 확률을 예측하지 않는다.

```text
KST 원본 CSV
→ 원본 검증 및 UTC 정제
→ 같은 지점의 정확한 1·3·6시간 전 관측 연결
→ 정확한 6시간 후 실제 파고를 정답으로 연결
→ 입력 또는 정답이 결측인 표본 제외
→ KST 달력 기준 시간순 분할 및 경계 침범 정답 제외
→ 학습 구간으로만 모델 학습
→ 검증 결과로 모델 선택 [완료]
→ 고정된 모델과 Persistence의 최종 테스트 평가 [미실행]
```

시각 간격이 불규칙하므로 행 번호 기준 shift가 아니라 지점·실제 시각으로
연결한다. 없는 시각을 보간하거나 0으로 채우지 않는다.
원본 시간대의 확인 근거는 사용자 보고이며 공식 답변 원문은 미첨부 상태다.

### 높은 파고 분석 기준

학습 구간의 정답 열 `target_significant_wave_height_6h_m`에서
`quantile(0.9)`로 계산한 값인 **1.0m**를 사용한다.
검증이나 테스트 정답의 분위수를 사용해 경계를 다시 정하지 않는다.

실제 정답이 1.0m 이상인 검증 표본은 233개(20.62%)이며,
실제 파고 범위는 1.0~2.9m다. 학습과 검증의 분포 및 같은 값의 반복 때문에
검증 표본의 정확히 10%가 되는 것은 아니다.
이 기준은 데이터 분석용이며 운항 위험 임계값이나 공식 안전 기준이 아니다.
미래 정답은 사후 평가 구간을 나누는 데만 사용하며 예측 입력에는 넣지 않는다.

### 최종 선택과 해석 범위

첫 배포 모델로 RandomForest를 선택한다. 전체 MAE가 비슷한 상황에서
전체 RMSE와 높은 파고 구간의 오차를 추가 근거로 사용한 결정이다.
단순성이 장점인 Ridge는 비교 결과로 보존한다.

이는 검증 결과를 탐색하며 정한 실용적인 선택이며, 실험 전에 정한
단일 MAE 최소화 규칙의 결과라고 소급해 주장하지 않는다.
최종 테스트 결과를 본 뒤 이 선택 근거를 유리하게 변경하지 않는다.

한 지점·한 해의 자료이며, 시간상 인접한 233개 표본은 독립적인
233개 사건을 뜻하지 않는다. 통계적 유의성이나 다른 해역의 우월성을
검증하지 않았다. 높은 파고 구간의 과소예측 비율도 약 68%이므로
운항 안전을 보장하는 모델로 표현하지 않는다.

## 6. 지표의 정확한 의미

각 표본에서 `error = predicted - actual`로 정의한다.

- MAE: `abs(error).mean()`.
- RMSE: `(error ** 2).mean() ** 0.5`.
- 평균 오차(bias): `error.mean()`. 음수는 평균적으로 낮게 예측함을 뜻한다.
- 과소예측 비율: `(error < 0).mean()`. 정확히 같은 예측은 과소예측이 아니다.
- 과소예측 시 평균 부족량: `(-error[error < 0]).mean()`.
  과소예측이 없으면 0으로 오해하지 않도록 계산 불가(N/A)와 건수 0을 보고한다.
- 전체 표본 기준 평균 부족량: `(-error).clip(lower=0).mean()`.
  과대예측은 0으로 포함하므로 앞의 조건부 평균과 분모가 다르다.

예: 실제 2.0m, 예측 1.5m이면 error=-0.5m이며 과소예측이다.
실제값·예측값의 인덱스가 동일해야 하며, 높은 파고 마스크를 양쪽에
같이 적용한다. 구간 표본이 없으면 N/A와 표본 수 0을 보고한다.

## 7. 고정할 모델 설정과 입력

현재 `train_random_forest()`의 설정을 변경하지 않는다.

```python
RandomForestRegressor(
    n_estimators=200,
    max_depth=10,
    min_samples_leaf=5,
    max_features=0.8,
    bootstrap=True,
    random_state=42,
    n_jobs=1,
)
```

| 설정 | 의미 |
| --- | --- |
| `n_estimators=200` | 트리 200개의 예측을 평균 |
| `max_depth=10` | 개별 트리의 최대 깊이 제한 |
| `min_samples_leaf=5` | 말단 노드에 최소 5개 학습 표본 유지 |
| `max_features=0.8` | 분기별 탐색 입력 특성 수 제한(현재 7개 중 5개) |
| `bootstrap=True` | 트리별로 복원추출한 학습 표본 사용 |
| `random_state=42` | 동일 환경에서 난수 절차 재현 |
| `n_jobs=1` | 병렬 작업 수 1 |

현재 설치 버전에서 확인한 나머지 기본값도 기록한다:
`criterion="squared_error"`, `min_samples_split=2`,
`min_weight_fraction_leaf=0.0`, `max_leaf_nodes=None`,
`min_impurity_decrease=0.0`, `oob_score=False`, `verbose=0`,
`warm_start=False`, `ccp_alpha=0.0`, `max_samples=None`, `monotonic_cst=None`.
현재 코드는 이 기본값을 모두 명시하지 않으므로 환경도 함께 유지한다.

입력은 아래 순서를 유지한 float64 7개 열이다.

1. `significant_wave_height_m`
2. `wind_speed_mps`
3. `station_pressure_hpa`
4. `wave_height_lag_1h_m`
5. `wave_height_lag_3h_m`
6. `wave_height_lag_6h_m`
7. `wave_height_change_1h_m`

정답은 `target_significant_wave_height_6h_m`이다.
관측소 ID·관측시각·정답시각·미래 관측값은 모델 입력에 추가하지 않는다.
입력 표준화, 새로운 특성, 예측값의 0 하한 처리, 보간 등을 추가하지 않는다.
