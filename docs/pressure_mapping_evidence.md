사용자의 비교 코드·실행 로그·연간 API 원문은 이 변경에 첨부되지 않았다.
향후 이 자료들을 보관하면 독립 재현 근거를 보강할 수 있다.

## 코드에 적용하는 정책

- 정책 버전을 `kma-buoy-experimental-v2`로 변경한다.
- 수치 일치 근거를 `numerically_matched_user_reported`로 기록한다.
- 정규화 열은 `api_pressure_hpa`를 유지해 공식 명칭과 출처를 보존한다.
- 모델 입력 연결 시 추가 기압 보정은 하지 않는다. 숫자 처리·모델 가중치는 바꾸지 않는다.
- 정규화한 관측이 모두 22101·KST 2025년·정시인 경우
  `within_user_reported_comparison_scope`로 표시한다.
  이는 해당 행을 새로 CSV와 대조했다는 뜻이 아니라 보고된 범위 안이라는 뜻이다.
- 다른 지점·연도·30분 자료 또는 혼합 입력은
  `outside_user_reported_comparison_scope`로 표시한다.
- 2026년 실시간 자료까지 수치 일치가 검증됐다고 표시하지 않는다.
- AQC/MQC 해석은 여전히 미확인이다. 기본 예측 차단 및
  `--allow-unverified-source` 실험 옵션을 유지한다.

내부 UTC 변환 후에도 대조 범위의 연도는 KST로 판단한다.
예를 들어 2024-12-31 15:00 UTC는 2025-01-01 00:00 KST이므로 2025년 범위다.
