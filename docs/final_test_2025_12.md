# 2025년 12월 최종 테스트 평가

평가일: 2026-10-26. 검증으로 선택한 RandomForest를 변경하지 않고 평가했다.

## 평가 조건

- 관측소: 덕적도 22101, 내부 시각 UTC / 달력 경계 KST
- 학습 3,891개 / 검증 1,130개 / 최종 테스트 728개
- 테스트 기준시각: 2025-12-01 00:00 이상, 2026-01-01 00:00 미만 KST
- 정답시각도 2026-01-01 00:00 전인 표본만 사용
- 테스트의 첫 기준시각: 2025-12-01 00:00 KST
- 마지막 정답시각: 2025-12-31 23:00 KST
- 모델 ID: `rf-22101-0c2a284dede20560`
- 모델: 트리 200개, 깊이 10, 리프 최소 5개, max_features=0.8, seed=42
- 입력: 기존 7개 특성 유지. 보간·예측값 보정·추가 특성 없음
- 비교: RandomForest와 현재값 유지(Persistence)만 평가. Ridge를 다시 비교해 선택하지 않음

학습 3,891개만으로 고정 설정의 RF를 재현해, 검증 구간의 예측과 파라미터가
기존 배포 모델과 일치하는지 먼저 확인했다. 테스트 예측 역시 두 모델이 정확히 일치했다.
실제 점수는 기존 배포 artifact의 예측으로 계산했으며 모델 파일·메타데이터는 수정하지 않았다.
학습+검증 결합 재학습, 하이퍼파라미터 변경, 모델 교체와 재배포는 하지 않았다.

## 전체 테스트 결과

| 방법 | 표본 수 | MAE(m) | RMSE(m) | 평균 오차(m) | 과소예측 비율 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 현재값 유지 | 728 | 0.253297 | 0.355491 | -0.001374 | 37.64% |
| RandomForest | 728 | 0.210335 | 0.296888 | -0.011460 | 44.92% |

현재값 유지 대비 RF의 MAE는 **약 16.96%**, RMSE는 **약 16.49% 감소**했다.
개선율은 `(기준 오차 - 모델 오차) / 기준 오차 × 100`이며 정확도 퍼센트가 아니다.
검증 RF의 MAE 0.192840m, RMSE 0.273583m보다는 오차가 커졌다.
검증과 테스트가 서로 다른 기간이므로 전체 차이를 특정 원인 하나로 단정하지 않는다.

## 상대적으로 높은 파고 구간

학습 정답의 90백분위수에서 미리 정한 **실제 파고 1.0m 이상** 기준을 그대로 썼다.
공식 위험 임계값이 아니며, 미래 정답은 평가 구간을 나누는 데만 사용했다.
해당 테스트 표본은 **209개**, 실제값 범위는 **1.0~2.2m**였다.

| 방법 | MAE(m) | RMSE(m) | 평균 오차(m) | 과소예측 | 과소예측 시 평균 부족량(m) |
| --- | ---: | ---: | ---: | ---: | ---: |
| 현재값 유지 | 0.392823 | 0.507221 | -0.194737 | 125/209, 59.81% | 0.491200 |
| RandomForest | 0.324137 | 0.431504 | -0.233673 | 159/209, 76.08% | 0.366610 |

RF는 이 구간에서도 MAE·RMSE는 낮았지만, **실제보다 낮게 예측한 비율과 음의 편향은
현재값 유지보다 컸다.** 과소예측했을 때의 평균 부족량은 작았다.
어떤 지표가 개선됐고 어떤 지표가 나빠졌는지를 구분해야 한다.
전체 오차 개선만으로 높은 파고를 놓치지 않는다거나 운항에 안전하다고 결론 내리지 않는다.
209개 인접 시간 표본이 209개 독립적인 사건을 뜻하지 않으며 통계적 유의성은 검증하지 않았다.

배포 메타데이터의 `test_re_evaluated=false`는 모델 내보내기 당시의 작업 기록이다.
평가 이력 전체를 나타내는 값이 아니며, 이를 true로 바꾸느라 기존 artifact를 변조하지 않았다.
현재 평가 완료 상태와 원시 결과는 본 문서 및 위 보고서에 기록한다.
