# 해양기상 관측 데이터 명세

## 1. 적용 범위

해양기상부이 CSV를 프로젝트 내부의 관측 레코드로 변환하는 규칙이다.

관측 레코드 한 개는 한 관측지점의 한 시각에 해당하는 자료다.
이 명세에는 예측 정답, 학습용 입력 변수, 위험 등급을 포함하지 않는다.

## 2. 원본 읽기

- 다운로드 원본을 보존한다.
- B1 샘플은 CP949로 엄격 디코딩한다.
- 디코딩할 수 없는 바이트를 대체 문자로 바꾸지 않고 오류로 처리한다.
- CSV의 쉼표 구분과 헤더를 해석한다.
- 파일 경로와 인코딩은 로더에 명시적으로 전달할 수 있도록 설계한다.

## 3. 원본 열과 내부 필드

| 원본 열       | 내부 필드                 | 내부 타입       | 단위             |
| ------------- | ------------------------- | --------------- | ---------------- |
| 지점          | station_id                | str             | 해당 없음        |
| 일시          | observed_at               | datetime        | UTC, 시간대 포함 |
| 풍속(m/s)     | wind_speed_mps            | float 또는 None | m/s              |
| 풍향(deg)     | wind_direction_deg        | float 또는 None | 도               |
| 현지기압(hPa) | station_pressure_hpa      | float 또는 None | hPa              |
| 습도(%)       | humidity_pct              | float 또는 None | %                |
| 기온(°C)      | air_temperature_c         | float 또는 None | °C               |
| 수온(°C)      | water_temperature_c       | float 또는 None | °C               |
| 유의파고(m)   | significant_wave_height_m | float 또는 None | m                |
| 평균파고(m)   | mean_wave_height_m        | float 또는 None | m                |

내부 필드 이름에 단위를 명시한다.
풍속과 파고 등을 다른 단위로 자동 변경하지 않는다.

현재 반환 형식은 pandas DataFrame이다. 기상 수치는 결측을 지원하는 `Float64`
타입으로 저장하고, 위 표의 `None`에 해당하는 값은 DataFrame 안에서 `pd.NA`로
표현한다. 관측시각은 UTC 시간대를 가진 pandas 날짜·시간 타입으로 저장한다.

## 4. 필수 열과 필수 값

필수 원본 열:

- 지점
- 일시
- 유의파고(m)

필수 열이 없으면 파일을 정상 입력으로 처리하지 않는다.

지점과 일시는 각 행에 반드시 값이 있어야 한다.
유의파고 열은 필수이지만, 개별 셀의 빈 값은 None으로 보존할 수 있다.

나머지 기상 요소의 열이 없으면 대응하는 내부 필드를 None으로 채운다.
추가 원본 열은 원본 파일에 보존하고, 현재 매핑 대상에 포함되지 않음을 식별한다.

## 5. 관측시각 규칙

2026-10-23 업데이트: 사용자가 연간 해양기상부이 시간 자료의 원본을 KST라고
확인해 전달했다. 현재 재처리는 `Asia/Seoul`로 해석한 뒤 UTC로 변환한다.
확인 근거의 수준, 재현 명령 및 한국 날짜 기준 분할은
[KST 재처리 기록](kst_reprocessing.md)을 따른다. 기존 UTC 가정 파일은 보존한다.

- B1 샘플의 원본 형식은 %Y-%m-%d %H:%M이다.
- 원본 시간대를 명시적으로 확인한다.
- 시간대 없는 문자열에 컴퓨터의 로컬 시간대를 자동 적용하지 않는다.
- 확인한 원본 시간대를 부여한 뒤 UTC로 변환한다.
- 내부 observed_at은 UTC 시간대가 있는 datetime이어야 한다.
- 원본 시간대가 미확정이면 UTC 변환의 정확성을 검증한 것으로 처리하지 않는다.

관측시각과 자료를 수신한 시각은 서로 다른 정보다.
이번 명세의 observed_at은 관측시각을 뜻한다.

## 6. 숫자와 빈 값 변환

- ".5"와 "0.5"는 모두 숫자 0.5로 변환한다.
- 앞뒤 공백을 제거한 뒤 빈 문자열이면 None으로 변환한다.
- 0은 유효한 수치로 보존하며, 빈 값으로 취급하지 않는다.
- 빈 값이 아닌 문자열의 숫자 변환 실패는 오류로 처리한다.
- NaN과 양수·음수 무한대는 허용하지 않는다.
- 공식적으로 확인되지 않은 숫자를 결측 대체값으로 임의 해석하지 않는다.

숫자 형태의 공식 결측 대체값이 확인되면,
그 근거와 적용 규칙을 명세에 추가한 뒤 변환에 반영한다.

## 7. 수치 검증 규칙

아래는 기본적인 형식·범위 검증이며, 관측 품질을 보장하는 검사는 아니다.
None인 값에는 수치 범위 검증을 적용하지 않는다.

- 풍속: 0 이상.
- 유의파고와 평균파고: 0 이상.
- 습도: 0 이상 100 이하.
- 풍향: 0 이상 360 이하. 360을 자동으로 0으로 변경하지 않는다.
- 현지기압: 0보다 큼.
- 기온과 수온: 유한한 숫자. 음수라는 이유만으로 거부하지 않는다.

샘플의 최솟값과 최댓값을 허용 범위로 사용하지 않는다.
범위를 벗어난 값을 조용히 잘라내거나 0으로 바꾸지 않는다.

## 8. 레코드 집합 규칙

- 관측 레코드의 식별 기준은 station_id와 observed_at의 조합이다.
- 같은 식별 기준의 중복이 있으면 임의로 첫 번째나 마지막 값을 선택하지 않는다.
- 중복은 오류로 보고하고 원인을 확인한다.
- 반환 레코드는 station_id, observed_at 순서로 정렬한다.
- 시간 간격이 항상 1시간이라고 가정하지 않는다.
- 없는 시각의 행을 CSV 로더에서 생성하지 않는다.
- 결측값 보간이나 관측값 집계는 CSV 로더에서 수행하지 않는다.

향후 6시간 뒤 정답을 연결할 때는 정확한 시각으로 연결한다.
6행 뒤의 값을 6시간 뒤의 값이라고 간주하지 않는다.

## 9. 오류 보고

입력 오류에는 가능한 범위에서 다음 정보를 포함한다.

- 파일 경로
- CSV 레코드 위치
- 원본 열 이름
- 문제가 된 원본 값
- 기대한 형식 또는 범위

오류가 있는 레코드를 조용히 버리지 않는다.
초기 로더는 오류 발생 시 처리를 중단하는 방식으로 구현한다.

## 10. 구현 전 확인 사항

- 원본 시간대는 사용자 보고로 KST를 반영했으며, 공식 답변 원문은 추가 확보 대상이다.
- 공식 결측 대체값과 품질정보 규칙은 아직 확인해야 한다.
- 원본 파일의 실제 다운로드 범위는 별도 확인이 필요하다.

B3-2에서 `read_buoy_csv()`와 `normalize_buoy_data()`를 구현하고,
로컬 단위 테스트와 실제 CSV 읽기·변환 통합 테스트를 수행했다.
이는 호출자가 지정한 시간대에 따른 변환 검증이며, 원본 CSV 시간대의 공식 확인은
별도 사항이다. 수치 범위·중복 검사와 정렬은 B3-3에서 구현할 예정이다.
